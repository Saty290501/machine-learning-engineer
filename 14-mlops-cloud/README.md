# MLOps & Cloud

Make ML systems reproducible, deployable, and observable.

## Topics

- [ ] Git workflows, code review, configuration, secrets, and environments.
- [ ] Docker images, reproducible builds, and container security basics.
- [ ] Experiment tracking and model registry with MLflow.
- [ ] Data/model versioning concepts and DVC.
- [ ] CI with linting, tests, type checks, and build validation.
- [ ] Deployment patterns on cloud infrastructure; start with one provider.
- [ ] Monitoring: service health, data quality, drift, performance, and cost.

## Practical deliverables

- [ ] Containerize one inference API.
- [ ] Add GitHub Actions for tests and linting.
- [ ] Track one experiment and document a rollback strategy.

## Completion evidence

- [ ] Runnable code or experiment
- [ ] Tests or validation checks
- [ ] Results with metric definitions
- [ ] Limitations and lessons learned
- [ ] Reproduction instructions
