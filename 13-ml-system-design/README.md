# ML System Design

Translate ML requirements into reliable system architectures.

## Topics

- [ ] Requirements: latency, throughput, freshness, availability, cost, privacy.
- [ ] Offline training, online inference, batch scoring, and streaming inference.
- [ ] Feature stores, feature freshness, point-in-time correctness.
- [ ] Model serving with FastAPI; synchronous and asynchronous patterns.
- [ ] Scaling, caching, queues, model replicas, and hardware trade-offs.
- [ ] Monitoring, fallback strategies, rollbacks, and graceful degradation.

## Practical deliverables

- [ ] Write architecture decision records for at least two system design exercises.
- [ ] Include data flow, failure modes, scaling bottlenecks, and trade-offs.

## Completion evidence

- [ ] Runnable code or experiment
- [ ] Tests or validation checks
- [ ] Results with metric definitions
- [ ] Limitations and lessons learned
- [ ] Reproduction instructions
