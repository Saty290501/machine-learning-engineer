# ML Algorithms from Scratch

Implement core algorithms to build intuition about their mechanics.

## Topics

- [ ] Linear regression with batch gradient descent.
- [ ] Logistic regression with stable sigmoid and binary cross-entropy.
- [ ] KNN with configurable distance metrics.
- [ ] K-Means with initialization and convergence criteria.
- [ ] Decision tree splits using Gini impurity or entropy.
- [ ] PCA using covariance eigendecomposition or SVD.
- [ ] A small neural network with forward pass and backpropagation.

## Practical deliverables

- [ ] Use NumPy for the core math; avoid calling the equivalent scikit-learn estimator.
- [ ] Compare outputs against a trusted library on controlled datasets.
- [ ] Add shape checks, numerical tests, and complexity notes.

## Completion evidence

- [ ] Runnable code or experiment
- [ ] Tests or validation checks
- [ ] Results with metric definitions
- [ ] Limitations and lessons learned
- [ ] Reproduction instructions
