# Agentic AI

Design controlled workflows that use models and tools reliably.

## Topics

- [ ] Agent patterns, planning, tool selection, and state transitions.
- [ ] Function calling, schema validation, retries, timeouts, and idempotency.
- [ ] LangChain and LangGraph workflows, state, persistence, and human approval.
- [ ] MCP concepts and secure tool integration.
- [ ] Multi-agent patterns: delegation, coordination, and failure containment.
- [ ] Memory design, guardrails, tracing, evaluation, and adversarial testing.

## Practical deliverables

- [ ] Build one bounded agentic workflow with explicit tools and a human approval step.
- [ ] Measure task success, tool errors, latency, and unsafe-action resistance.

## Completion evidence

- [ ] Runnable code or experiment
- [ ] Tests or validation checks
- [ ] Results with metric definitions
- [ ] Limitations and lessons learned
- [ ] Reproduction instructions
