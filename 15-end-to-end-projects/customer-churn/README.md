# Customer Churn Prediction

**Goal:** predict customer churn and translate model scores into useful retention decisions.

## Planned engineering scope
- Dataset provenance, target definition, and leakage audit.
- Exploratory analysis and a simple baseline.
- Logistic regression and tree-based model comparison.
- Stratified validation, PR-AUC/ROC-AUC, recall at an operating threshold, calibration.
- Explainability with feature importance and SHAP where appropriate.
- Reproducible training pipeline and FastAPI inference endpoint.
- Tests, Docker packaging, and model card.

**Status:** Planned. No performance claims until experiments are run and recorded.
