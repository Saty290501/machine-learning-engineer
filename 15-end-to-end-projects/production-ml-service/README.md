# Production ML Service

**Goal:** package a trained model behind a maintainable inference service.

## Planned engineering scope
- Training script and versioned configuration.
- Experiment tracking and model artifact registration.
- FastAPI service with schema validation.
- Unit, integration, and contract tests.
- Docker image and GitHub Actions CI.
- Structured logs, health checks, latency/error metrics, and rollback notes.

**Status:** Planned. Deploy to a cloud environment only after local tests and secrets handling are in place.
