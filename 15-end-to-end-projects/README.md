# End-to-End Projects

Demonstrate complete ownership from problem framing to operational readiness.

## Topics

- [ ] Customer churn: baseline, calibrated model, explainability, API.
- [ ] Fraud detection: class imbalance, thresholding, streaming design, monitoring.
- [ ] Recommendation system: candidate generation, ranking, offline evaluation.
- [ ] Enterprise RAG assistant: ingestion, hybrid search, reranking, evaluation, UI.
- [ ] Agentic workflow: graph orchestration, tools, approvals, tracing.
- [ ] Production ML service: training pipeline, registry, Docker, CI/CD, monitoring.

## Practical deliverables

- [ ] Each project must include problem statement, dataset provenance, architecture, setup, tests, evaluation, limitations, and next steps.

## Completion evidence

- [ ] Runnable code or experiment
- [ ] Tests or validation checks
- [ ] Results with metric definitions
- [ ] Limitations and lessons learned
- [ ] Reproduction instructions
