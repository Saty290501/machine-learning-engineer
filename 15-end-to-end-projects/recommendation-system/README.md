# Recommendation System

**Goal:** build a retrieval-and-ranking recommendation pipeline.

## Planned engineering scope
- Define user/item interactions and time-aware splits.
- Popularity baseline and collaborative filtering.
- Candidate generation and ranking separation.
- Offline metrics such as Recall@K, MAP@K, and NDCG@K.
- Cold-start analysis, bias, diversity, and feedback loops.
- API contract and latency considerations.

**Status:** Planned. No performance claims until experiments are run and recorded.
