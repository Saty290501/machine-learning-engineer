# Fraud Detection

**Goal:** detect rare, costly events while managing false positives and operational latency.

## Planned engineering scope
- Dataset provenance and temporal split.
- Leakage and class-imbalance analysis.
- Baselines, PR-AUC, recall at fixed precision, cost-sensitive thresholding.
- Calibration and error analysis.
- Batch scoring first; streaming architecture as a documented extension.
- Monitoring plan for data drift, alert volume, and delayed labels.

**Status:** Planned. No performance claims until experiments are run and recorded.
