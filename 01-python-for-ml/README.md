# Python for Machine Learning

Write maintainable Python for data-intensive and ML workloads.

## Topics

- [ ] Intermediate Python: iterators, generators, comprehensions, decorators, context managers, typing, exceptions.
- [ ] Data structures, complexity, OOP, clean interfaces, and useful design patterns.
- [ ] NumPy: vectorization, broadcasting, indexing, numerical stability.
- [ ] Pandas: joins, groupby, missing values, time series, efficient transformations.
- [ ] Visualization with Matplotlib; exploratory analysis with clear questions.
- [ ] Testing with pytest, environments, packaging, logging, and reproducible scripts.

## Practical deliverables

- [ ] Build a small reusable data-validation package.
- [ ] Write tests for edge cases and compare vectorized code with a simple baseline.

## Completion evidence

- [ ] Runnable code or experiment
- [ ] Tests or validation checks
- [ ] Results with metric definitions
- [ ] Limitations and lessons learned
- [ ] Reproduction instructions
