# Learning roadmap

Organize the journey into measurable milestones, not a checklist of buzzwords.

## Topics

- [ ] Consolidate Python, math, and data foundations.
- [ ] Build classical ML models and evaluate them correctly.
- [ ] Implement selected algorithms from scratch to understand their mechanics.
- [ ] Train deep-learning models and understand optimization and generalization.
- [ ] Explore NLP, computer vision, LLMs, RAG, and agentic workflows.
- [ ] Ship end-to-end systems with tests, APIs, containers, CI, and monitoring.

## Practical deliverables

- [ ] A topic is complete only when there is an explanation, a runnable artifact, tests or validation, and a short reflection.

## Completion evidence

- [ ] Runnable code or experiment
- [ ] Tests or validation checks
- [ ] Results with metric definitions
- [ ] Limitations and lessons learned
- [ ] Reproduction instructions
