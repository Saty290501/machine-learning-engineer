# Interview Preparation

Organize concise, technically accurate explanations and coding practice.

- `python/`: data structures, complexity, iterators, OOP, testing.
- `sql/`: joins, CTEs, window functions, aggregation, query optimization.
- `machine-learning/`: assumptions, metrics, validation, leakage, bias-variance.
- `deep-learning/`: backpropagation, optimizers, normalization, CNNs, transformers.
- `ml-system-design/`: architecture, scale, monitoring, reliability, trade-offs.
- `generative-ai/`: tokenization, embeddings, RAG, fine-tuning, evaluation, agents.

For each answer: define the concept, explain why it matters, give a practical example, mention trade-offs, and identify common failure modes.
