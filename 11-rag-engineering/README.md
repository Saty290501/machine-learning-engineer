# RAG Engineering

Build retrieval systems whose quality can be measured.

## Topics

- [ ] Document ingestion, parsing, metadata, chunking, and provenance.
- [ ] Dense embeddings, vector indexes, FAISS, and Chroma.
- [ ] Lexical retrieval with BM25 and hybrid retrieval.
- [ ] Rank fusion, reranking, query rewriting, and metadata filtering.
- [ ] Grounded generation, citations, abstention, and context construction.
- [ ] Evaluation: Recall@k, MRR, nDCG, faithfulness, answer relevance, latency.
- [ ] Advanced topics: multimodal retrieval, access control, incremental indexing.

## Practical deliverables

- [ ] Evolve the existing local RAG assistant into a documented benchmarked system.
- [ ] Compare dense-only, BM25-only, and hybrid retrieval on a labeled query set.
