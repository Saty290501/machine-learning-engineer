# Resources

This is a working shelf, not a list of links I collected once and forgot. I keep a resource here when it helps me answer a question in one of the seven sections.

## How I use the shelf

- **Books** give me a connected mental model. The [reading plan](books.md) says what I would read first and what I would leave for later.
- **Courses** give me a schedule, explanations, and exercises when a book chapter is too abstract.
- **Documentation** is where I check current behavior, parameters, and API details.
- **Papers** show the original problem, assumptions, and evidence behind methods I now meet in practice.

For each new note, I try to answer: *What did this help me understand, what did I try afterward, and what still feels unclear?* I update changing links when I revisit them. I do not mark a resource as read just because it is bookmarked.
