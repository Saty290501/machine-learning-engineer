# Courses and guided material

I use a course when its sequence or exercises fill a gap that a book leaves open. I do not plan to complete several courses at once.

| Resource | Best use in this roadmap | Notes |
|---|---|---|
| [MIT 18.06 Linear Algebra](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/) | Build visual intuition for systems of equations, vector spaces, eigenvalues, and matrix factorizations. | Free lecture videos, problem sets, and solutions. Pair a lecture with a small NumPy experiment. |
| [ISL with Python labs](https://www.statlearning.com/) | Practice regression, classification, resampling, trees, SVMs, and unsupervised learning. | Free book and labs; use the labs to check understanding, then write a fresh experiment of my own. |
| [Stanford CS229](https://cs229.stanford.edu/) | Revisit the mathematical framing and assumptions behind core ML methods. | Use the public notes as a reference sequence; choose topics that match the current section rather than trying to consume every material at once. |
| [Stanford CS224N](https://web.stanford.edu/class/cs224n/) | Study modern NLP models, embeddings, attention, and transformer-based tasks. | The current course includes deep learning. I will use only the NLP material needed for this repo and keep the project scope to text tasks. |
| [Natural Language Processing with Python (NLTK Book)](https://www.nltk.org/book/) | Get a guided, inspectable introduction to text processing, classification, information extraction, and syntax. | A free online book updated for Python 3 and NLTK 3; useful for classical NLP exercises. |

Before I follow an assignment, I check its current version and prerequisites. Archived course pages can be excellent references, but their setup instructions may no longer match current package releases.
