# Documentation I return to

When I need the exact behavior of a library, I check its documentation before copying a snippet from an old notebook.

| Documentation | Where it helps |
|---|---|
| [Python tutorial](https://docs.python.org/3/tutorial/) | Language basics, data structures, functions, modules, exceptions, and iterators |
| [NumPy user guide](https://numpy.org/doc/stable/user/) | Array shapes, broadcasting, indexing, random generation, and numerical operations |
| [pandas user guide](https://pandas.pydata.org/docs/user_guide/) | Missing data, joins, reshaping, groupby, time series, and IO |
| [Matplotlib users guide](https://matplotlib.org/stable/users/index.html) | Plots that make distributions, comparisons, and residuals readable |
| [scikit-learn user guide](https://scikit-learn.org/stable/user_guide.html) | Pipelines, model selection, preprocessing, metrics, and estimator behavior |
| [NLTK Book](https://www.nltk.org/book/) | Classical text processing, corpus access, tokenization, and introductory NLP |
| [Hugging Face Transformers documentation](https://huggingface.co/docs/transformers/) | Current tokenizer and model workflows for focused NLP experiments |

For every result I keep, I record the package versions and the command used to reproduce it. Stable docs explain concepts; versioned API docs explain the behavior I actually ran.
