# Contributing

This repository is primarily a personal learning portfolio, but constructive suggestions are welcome.

## Standards
- Keep changes focused and explain the motivation.
- Prefer small, reproducible examples over large unstructured notebooks.
- Include tests or validation for code changes.
- Do not commit credentials, private datasets, or copyrighted course material.
- Document assumptions, metrics, limitations, and reproduction steps.
- Never invent benchmark numbers or mark planned work as completed.
